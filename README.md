# Real Shrooms (Fabric 1.20.1)

Реалістичні гриби для Minecraft Java 1.20.1 на Fabric.

## Що додає
| Гриб | Де росте | Властивості |
|---|---|---|
| Лисичка | ліси, тайга | їстівна |
| Білий гриб | ліси, тайга | їстівний, найситніший |
| Зморшок | листяні ліси, рідкісний | сирий токсичний, смажити в печі/коптильні/на багатті |
| Мухомор червоний | березові ліси, тайга | отруйний (нудота, слабкість) |
| Бліда поганка | ліси, темний ліс | смертельно отруйна |
| Чорнильний гнойовик | болото, мангри, темний ліс, луки | 2 шт. = мішечок із чорнилом |

Реалістичність:
- Після дощу гриби поширюються приблизно вчетверо швидше.
- Лисичка, білий гриб, зморшок, мухомор і поганка поширюються тільки поруч із деревами (мікориза).
- Гриби не збиваються в надто щільні гущі.
- Усе, що можна їсти, можна й посадити (як солодкі ягоди): клік по землі садить, клік у повітря їсть.
- Рецепт: миска + лисичка + білий гриб = грибний суп.

## Збірка
1. Встанови JDK 17.
2. У папці проєкту: `./gradlew build` (Windows: `gradlew.bat build`).
3. Готовий мод: `build/libs/realshrooms-1.0.0.jar` (не файл із `-sources`).
4. Поклади jar у `mods` разом із Fabric Loader для 1.20.1 та Fabric API (0.92.2+1.20.1 або новіший для 1.20.1).

Для редагування відкрий папку в IntelliJ IDEA як Gradle-проєкт.

## Структура
- `src/main/java/com/realshrooms/`: код (блок, реєстрація, клієнтська частина)
- `src/main/resources/data/realshrooms/worldgen/`: де і як часто з'являються гриби
- `tools/gen_assets.py`: скрипт, який генерує текстури та JSON-файли ресурсів

## Збірка без встановлення Java (GitHub Actions)
1. Створи безкоштовний акаунт і порожній репозиторій на github.com.
2. Завантаж у нього вміст цієї папки (Add file → Upload files; не забудь приховану папку `.github`).
3. Відкрий вкладку Actions → дочекайся зеленої галочки → у запуску внизу завантаж артефакт `realshrooms-jar`.
4. У архіві візьми `realshrooms-1.0.0.jar` (не `-sources`).
